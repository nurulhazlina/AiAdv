2.1 — How Machines Learn

The training loop and the three flavours of machine learningGelung latihan dan tiga rasa pembelajaran mesin

⏱ 6 min ○
A machine learns by adjusting its internal parameters based on data, so that its future predictions become progressively more accurate. Unlike traditional programming — where a human writes explicit rules — an ML model discovers the rules itself from examples.

The Training Loop

📦
Data In
Feed labelled or unlabelled examples to the model
🔮
Predict
Model makes a prediction or finds structure
📐
Measure Error
Compare output against target or reward signal
🔧
Adjust
Update weights to reduce error next time

Repeat thousands of times → a trained modelUlang beribu kali → model terlatih

Three Learning Flavours

TypeHas Labels?Learning SignalKey Question
Supervised✅ YesCorrect answer provided"What is this?"
Unsupervised❌ NoFinds patterns in raw data"What groups exist?"
Reinforcement➕ RewardReward / penalty from environment"What action is best?"
Key TakeawayAll three flavours use the same loop — data in, predict, measure, adjust — but differ in what kind of feedback guides the adjustment.Ketiga-tiga rasa menggunakan gelung yang sama — data masuk, ramal, ukur, laras — tetapi berbeza dalam jenis maklum balas yang membimbing pelarasan.

2.2 — Supervised Learning

Learn from labelled examples — then classify a new farm birdBelajar daripada contoh berlabel — kemudian klasifikasikan burung ladang baharu

⏱ 10 min ○
In supervised learning, every training example comes with a label — the correct answer. The model learns a mapping from features → label.Dalam pembelajaran terarah, setiap contoh latihan disertakan dengan label — jawapan yang betul. Model mempelajari pemetaan daripada ciri → label.

2.4 — Reinforcement Learning

An agent learns by trial-and-error — navigate the farm to the foodEjen belajar melalui cuba-dan-ralat — navigasi ladang ke makanan

⏱ 10 min ○
Reinforcement learning uses a different signal: reward. An agent takes actions in an environment, receives positive or negative rewards, and gradually learns a policy — a strategy that maximises total reward over time.
