Find & Fix the Mistakes Diagnose & Correct

Each card below contains a wrong statement about AI or Machine Learning. Read it carefully, spot the error, and type the corrected version.

Mistake 1 — Confused layer types

❌ "The hidden layer is always the first layer of a neural network — it is where raw input data enters the model."

Raw data enters the input layer, not the hidden layer. What is the correct order of layers?

Think about the word "hidden" — if it is in the middle, what comes before it?Fikirkan siapa yang membuat kerja: dalam pengaturcaraan tradisional, adakah data yang menentukan peraturan, atau pengaturcara?

Mistake 2 — Wrong direction

❌ "In backpropagation, the error signal travels forward through the network — from input to output — to update the weights layer by layer."

Backpropagation travels BACKWARD — from output to input. How does the error signal actually flow?

The name "back" propagation tells you the direction. Where does the error come from, and in which direction does it travel to fix the weights?Jika pembelajaran diselia menggunakan label… apakah nama jenis PM yang berfungsi tanpa label?

Mistake 3 — Wrong activation role

❌ "Activation functions are only used in the output layer of a neural network — they are what produce the final prediction."

Activation functions are used in HIDDEN layers too. What is their key role there?

Without activation functions in hidden layers, stacking many layers would be the same as having just one — why?
