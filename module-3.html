3.1 Data and Features

What does a model actually learn from? Understanding inputs, features, and labels.Apakah yang sebenarnya dipelajari oleh model? Memahami input, ciri, dan label.

⏱ 6 min ○

Before a model can learn anything, it needs information — just like you need to know something about a student before you can guess whether they'll pass an exam. We call each piece of information a feature.Sebelum model boleh belajar apa-apa, ia memerlukan maklumat — seperti anda perlu tahu sesuatu tentang pelajar sebelum boleh meneka sama ada mereka akan lulus peperiksaan. Kami memanggil setiap keping maklumat sebagai ciri.

Feature — One piece of information about an example. If you're predicting exam results, features might be: hours studied, hours slept, age.Ciri — Satu keping maklumat tentang contoh. Jika anda meramalkan keputusan peperiksaan, ciri mungkin: jam belajar, jam tidur, umur.
Types of Features
🔢
Numerical
Plain numbers — the model can use these directly as they are.
e.g. Temperature, price, age, study hours
🏷️
Categorical
Labels or groups — must be converted to numbers first.
e.g. Colour, city, subject name
📝
Text
Words — converted into numbers by counting words or using AI "meaning" scores.
e.g. Reviews, tweets, emails
🖼️
Image
Photos — each pixel is just a number from 0 (black) to 255 (white).
e.g. Photos, X-rays, drawings

Raw data is rarely ready to use. A date like "2024-03-15 08:32" means nothing to a model — but "hour=8, is_morning=1, weekday=5" does! This is called feature engineering. Pick a tab and try the transformations.Data mentah jarang bersedia untuk digunakan. Tarikh seperti "2024-03-15 08:32" tidak bermakna apa-apa kepada model — tetapi "hour=8, is_morning=1, weekday=5" bermakna! Ini dipanggil kejuruteraan ciri. Pilih tab dan cuba transformasi.

A date-time string like "2024-03-15 08:32:00" is just text — the model can't do maths on it. So we pull out the useful parts: the hour, the day of the week, whether it's morning. Now the model has real numbers it can learn from. 📅 → 🔢
"Absolutely amazing product!!"
→
word_count=3 char_count=27 sentiment=0.97 exclamations=2 avg_word_len=7.3 caps_ratio=0.04
A model can't read words — it can only read numbers. So we count things: how many words? How many exclamation marks? Is the overall feeling positive or negative? These counts and scores become the features. Simple but powerful! 💬 → 🔢
colour = "Red"
→
colour_Red=1 colour_Blue=0 colour_Green=0 colour_Yellow=0
One-hot encoding — If we wrote Red=1, Blue=2, Green=3, the model might think Green is "three times Red" — which is nonsense! Instead, each colour gets its own yes/no column. Red? Yes=1, No=0. Blue? No=0. Only one column is ever 1 at a time. 🎨 → 🔢
income = 85000
→
income_norm=0.42 income_log=11.35 income_bracket=3
Numbers still need rescaling. An income of 85,000 next to an age of 25 — the model might think income is 3,400× more important just because the number is bigger! We shrink everything to a similar range: 0 to 1. Now age and income are on equal footing. ⚖️ → 🔢
Label — The correct answer you want the model to learn to predict. Features describe the input; the label is the right output.Label — Jawapan betul yang anda ingin model pelajari untuk meramal. Ciri menerangkan input; label adalah output yang betul.
Key Takeaway"Rubbish in, rubbish out" — if your features are messy, wrong, or missing important information, even the cleverest algorithm will fail."Sampah masuk, sampah keluar" — jika ciri anda tidak kemas, salah, atau tiada maklumat penting, walaupun algoritma paling pintar akan gagal.

3.2 The ML Training Process

Forward pass, loss, backpropagation, weight update — the learning cycle explained.Laluan hadapan, kehilangan, perambatan balik, kemas kini pemberat — kitaran pembelajaran dijelaskan.

⏱ 7 min ○

How does a model actually learn? Think about learning to shoot a basketball. You throw → you see how far off you were → you adjust your aim → you throw again. Repeat. The model does exactly the same thing with numbers.Bagaimana model sebenarnya belajar? Fikirkan tentang belajar menembak bola keranjang. Anda lempar → anda lihat sejauh mana anda tersasar → anda laraskan bidikan → anda lempar lagi. Ulang. Model melakukan perkara yang sama dengan nombor.

🏀 The Basketball Analogy — how a model learns
🏀 Throw→Feed data through model
👀 See miss→Measure the error (Loss)
🤔 Analyse→Backpropagation
🔧 Adjust aim→Update the weights
🔁 Throw again→Next epoch — repeat!
Each throw = one training loop. Watch the loss fall as the model adjusts its aim!

📏 Loss
How wrong am I right now?
Loss measures the gap between the robot's guess and the correct answer. Big miss = high loss. Perfect answer = loss ≈ 0. Training's entire job is to shrink this number towards zero.
🏀 Like basketball: a wild miss has huge loss. A perfect swish = loss ≈ 0.
Loss = (prediction − truth)²
🔄 Epoch
One full pass through all examples
Each time the robot looks at ALL training examples once = 1 epoch. The plant robot's "Round" button = 1 epoch! More epochs = more practice = lower loss — but too many causes problems (see below).
📖 Like reading a textbook. One read-through = 1 epoch. You need many reads before the exam!
🌱 Plant robot — ~15 rounds (epochs)
🖼️ Image classifier — 50–200 epochs
🤖 GPT-style model — millions of steps on billions of words
⚡ Learning Rate
How big is each adjustment?
After every wrong guess the model tweaks its weights. The learning rate decides how much to tweak.
🐢 Too small → loss falls incredibly slowly
🎯 Just right → smooth, steady learning
🐇 Too big → overshoots, loss bounces around
⛷️ See Simulation 2 above — the orange ball IS the learning rate in action!
Sweet spot ≈ 0.001 – 0.01
⚠️ Too few epochs or too many? Both cause trouble!
😴
Underfitting
Too few epochs — the model hasn't practiced enough. It's still mostly guessing. Like leaving an exam after reading the textbook only once.
🎯
Just right!
The model learned the real pattern and handles new examples it has never seen. This is the goal of every ML project.
🤯
Overfitting
Too many epochs — the model memorised every training example but can't handle anything new. Like reciting the textbook word-for-word without understanding a thing.
Key Takeaway — Training = repeating the same loop (look at data → measure loss → adjust weights → repeat) hundreds or thousands of times. Each loop = one step down the loss curve.Latihan = mengulangi gelung yang sama (lihat data → ukur kehilangan → laras pemberat → ulang) ratusan atau ribuan kali. Setiap gelung = satu langkah menuruni lengkung kehilangan.

🧱 Inside the Network — Layer by Layer

Every neural network has three kinds of layers — here's what each one does to your data as it flows through.Setiap rangkaian neural mempunyai tiga jenis lapisan — inilah yang dilakukan setiap satu kepada data anda semasa ia mengalir.

IN
Input Layer
"What the model sees." Each neuron holds one raw feature — e.g. sunny days, days dry. No maths happens here, just passing numbers in.
H
Hidden Layer(s)
"What the model thinks about it." These neurons combine features into patterns the model discovered. More neurons = more complex shapes it can detect.
OUT
Output Layer
"The model's answer." One neuron per class (e.g. Water, Skip). The brightest one wins — that's the prediction. Softmax turns these into percentages that add to 100%.

📚 Key Concepts
⚖️ Weights & Bias
The numbers training actually changes
Every line in the network has a weight — a number saying how strongly that connection matters. Bias is a constant offset added before the activation so the neuron isn't stuck at zero. Together they let each neuron tune its sensitivity.
🎚️ Like mixing sliders on a soundboard. Training finds the perfect mix of all sliders at once.
output = Σ(inputs × weights) + bias
🔀 Activation Function
The neuron's on/off decision
Without an activation, stacking layers is pointless — the maths collapses into one flat equation. Activations add the curves and bends that let the network learn complex patterns, not just straight lines.
ReLU → max(0, x). If negative, kill it. Most used in hidden layers.
Sigmoid → squish to 0–1. Good for "how likely is this?"
Softmax → split output into % that add to 100. Used for final prediction.
⬅️ Backpropagation
How mistakes travel backwards
After a wrong prediction, the error flows backwards through every layer. Each weight gets a tiny blame score: "you made this error bigger/smaller by this much." Then every weight nudges in the direction that reduces the loss.
🎯 Like a coach reviewing game tape and telling each player exactly what to fix — and by how much.
predict → measure loss → blame backwards → update weights
Key Takeaway — A neural network is layers of neurons, each doing simple maths (multiply by weights + bias → squeeze through activation). The magic is backpropagation: after every prediction, errors flow backwards, nudging every weight in the right direction.Rangkaian neural adalah lapisan neuron, setiap satu melakukan matematik mudah (darab dengan pemberat + pincang → picit melalui pengaktifan). Keajaiban adalah perambatan balik: selepas setiap ramalan, ralat mengalir ke belakang, menolak setiap pemberat ke arah yang betul.

📖 Image Processing — Key Terms
🟫
Pixel
The smallest unit of an image — short for "picture element." A 720p frame = 1,280 × 720 = 921,600 pixels.
🔴🟢🔵
RGB Channels
Each colour pixel stores 3 numbers (0–255): Red, Green, Blue. Mixed together they can make any of 16 million colours.
⬛
Grayscale
A 1-channel image — one number per pixel: 0 = black, 255 = white. Simpler, so faster to process.
📐
Resolution
Width × Height in pixels. A 28×28 digit has 784 pixels. A 4K video frame has over 8 million.

CNNs are specialised networks designed for images. Instead of connecting every pixel to every neuron, they use small filters that slide across the image detecting edges, textures and shapes.CNN adalah rangkaian khusus yang direka untuk imej. Bukannya menghubungkan setiap piksel ke setiap neuron, mereka menggunakan penapis kecil yang meluncur merentasi imej mengesan tepi, tekstur dan bentuk.

🔬 What is Convolution?

Convolution is the mathematical heart of every CNN. A tiny filter (or kernel) — typically 3×3 numbers — slides one step at a time across an image. At each position it multiplies its values with the overlapping pixels and sums them up.Konvolusi adalah jantung matematik setiap CNN. Penapis kecil (atau kernel) — biasanya 3×3 nombor — meluncur satu langkah pada satu masa merentasi imej. Di setiap kedudukan ia mendarabkan nilainya dengan piksel bertindih dan menjumlahkannya.

1
Place the filter
Line up the 3×3 filter over the top-left corner of the image. It covers exactly 9 pixels.
2
Multiply & sum
Multiply each filter weight by the matching pixel value, then add all 9 products. One output number.
3
Slide & repeat
Move the filter one pixel right (or down). Repeat until the entire image is covered — building the feature map.
4
Use many filters
A real CNN uses dozens of different filters per layer — one learns edges, another curves, another colour gradients.

📊 Why CNNs Beat Regular Networks for Images
A 256×256 colour image has 196,608 pixels. One fully-connected layer to 1,000 neurons needs 196 million weights. A CNN with 32 filters needs only ~9,000 — because the same filter is reused across positions. Press Animate to see the difference.
🔄 Transfer Learning — Borrow What's Already Learned
A CNN pretrained on millions of images has already learned edges, curves, and textures. Freeze those layers and train only a new output layer on your small dataset. You get powerful features without huge data.
Key TakeawayEarly layers detect edges and colours. Middle layers detect textures and shapes. Deep layers detect complex objects. This learned hierarchy of features is what makes deep learning powerful.Lapisan awal mengesan tepi dan warna. Lapisan tengah mengesan tekstur dan bentuk. Lapisan dalam mengesan objek kompleks. Hierarki ciri yang dipelajari inilah yang menjadikan pembelajaran mendalam berkuasa.

Accuracy alone isn't enough — precision, recall, F1, and the confusion matrix.Ketepatan sahaja tidak cukup — ketepatan, daya ingat, F1, dan matriks kekeliruan.

A model that's 99% accurate on a cancer screening test might still be useless — if only 1% of cases are positive, always predicting "no cancer" gives 99% accuracy! We need better metrics.Model dengan ketepatan 99% pada ujian saringan kanser mungkin masih tidak berguna — jika hanya 1% kes adalah positif, sentiasa meramal "tiada kanser" memberi ketepatan 99%! Kita memerlukan metrik yang lebih baik.

Accuracy
correct / total
Good when classes are balanced. Misleading when they're not.
Precision
TP / (TP+FP)
Of all positive predictions, how many were correct? Minimises false alarms.
Recall
TP / (TP+FN)
Of all real positives, how many did we catch? Minimises missed cases.
F1 Score
2·P·R/(P+R)
Harmonic mean of precision and recall. Balances both.
